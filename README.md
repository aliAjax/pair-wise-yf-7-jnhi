# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、检查字模数量是否超用、保存草稿并导出PNG预览图。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 纸张领用

裁纸间不再靠纸条记单，页面下方「纸张领用」按草稿走单，数据只存浏览器（localStorage，键 `zfl16-paper-requisitions`，与排版草稿互不影响）。

业务规则：

- 换算：明信片每张原纸出 2 张、书签 4 张、方形小笺 3 张；成品张数换算原纸张数时向上取整。
- 提交领料先**预留**库存（扣减批次库存）；**撤单**把原纸如数归还批次。
- 预留后可**开工出库**；已开工的领料批次锁定，不能换批次，也不能撤单。
- **完工登记**后，边角（领出整纸可切成品数 − 实际成品数，按小张计）回到原批次存档。
- 库存不足、批次停用、草稿已有未结领料（预留中或已开工）时，页面说明原因，库存不动。
- 批次可登记新批次、停用存档、重新启用；停用批次不能领入或换入。

代码按三块分开维护，互不依赖 DOM / 存储实现：

| 文件 | 职责 |
| --- | --- |
| `paper-convert.js` | 纸张换算：成品张数 ↔ 原纸张数、向上取整、边角小张数 |
| `paper-store.js` | 批次存档：批次与领料单状态机（预留 / 已开工 / 已完工 / 已撤单）、校验与 localStorage 持久化 |
| `paper-ui.js` | 页面接入：领用表单、记录、批次管理的渲染与交互；不改动排版主程序 `app.js` |
