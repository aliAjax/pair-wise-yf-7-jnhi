# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、检查字模数量是否超用、保存草稿并导出PNG预览图。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 纸张领用

裁纸间不再靠纸条记单。页面下方可开领料单：选草稿和原纸批次、填成品张数，按纸型换算原纸（明信片每张原纸出2张、书签出4张、方形小笺出3张，换算后向上取整）。

- 提交先预留库存；库存不足、批次停用或草稿已有未结领料时，页面说明原因且库存不动。
- 预留中的领料单可撤单（原纸归还批次）或换批次；已开工的领料不能换批次。
- 开工出库后，裁剩的边角自动回原批次（如方形4张用1⅓张原纸，预留2张，边角⅔张回批次）。
- 批次可入库、停用/启用，库存以 1/12 张为最小单位精确记录。

三个部分分开维护：

| 文件 | 职责 |
| --- | --- |
| `paper-conversion.js` | 纸张换算：成品张数 ↔ 原纸张数、边角、分数张格式化 |
| `paper-store.js` | 批次存档：批次与领料单的状态流转，数据只存浏览器（localStorage `zfl16-paper-room`） |
| `paper-ui.js` | 页面接入：渲染领用区、读写草稿列表（由 `app.js` 经 `window.WorkshopApp` 提供） |

## 测试

`node test-paper.js` 可跑换算与库存流转的逻辑测试（纯 Node，无依赖）。
